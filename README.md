CPU Scheduling Visualizer 🚀

An animated Operating System mini project that visualizes CPU Scheduling Algorithms through interactive simulations and modern UI design.

Features
FCFS Scheduling
Round Robin Scheduling
Animated Ready Queue
CPU Execution Visualization
Dynamic Gantt Chart
Waiting Time (WT) Calculation
Turnaround Time (TAT) Calculation
Futuristic Dark UI
Responsive Design
Tech Stack
Next.js
React
Tailwind CSS
Framer Motion
TypeScript
Installation

## Installation

Clone the repository:

```bash
git clone <your-repo-link>
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

This project was developed as a 4th Semester Operating Systems Mini Project to help students better understand CPU Scheduling Algorithms using animated visual simulations.

Algorithms Implemented
FCFS (First Come First Serve)

Processes are executed in the order they arrive.

Round Robin (RR)

Each process gets CPU time based on a fixed time quantum.
